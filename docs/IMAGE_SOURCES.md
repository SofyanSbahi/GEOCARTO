## Ce qu'il faut faire (décision de Sofyan)
1. Remplir la colonne « Source » (auteur, URL ou ouvrage, licence, date de consultation) pour chaque image.
2. Pour les captures **Google Maps / Earth** : respecter les règles d'attribution de Google pour l'usage choisi ou les remplacer (par des images libres, p. ex. Wikimedia Commons ou des données ouvertes que vous produisez).
3. Pour les **cartes officielles** : obtenir l'autorisation de l'éditeur ou les remplacer par des cartes sous licence ouverte.
4. Pour les images libres : copier la licence et l'attribution exigée (souvent obligatoire même pour une licence libre).
5. Mettre à jour `tools/site-extra/CREDITS.txt` avec les attributions réelles, puis republier.

Le texte de `CREDITS.txt` actuel **ne prétend pas** que les droits sont acquis : il dit que les droits restent à leurs détenteurs et que la vérification est en cours. Remplacer des images changerait l'interface : à faire dans une version ultérieure, pas dans la rc.3 (comparabilité de l'essai).
